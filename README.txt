دعوة زفاف أنس ومريم — نسخة الرابط العام والروابط الخاصة

الرابط العام بدون اسم:
https://YOUR-DOMAIN/
أو:
https://YOUR-DOMAIN/general.html

الرابط الخاص بكود:
https://YOUR-DOMAIN/?id=F9K82L

إنشاء الروابط من Excel:
1. افتح generator.html.
2. اكتب رابط الدعوة الأساسي.
3. ارفع Excel فيه عمود Name أو الاسم.
4. يمكن إضافة MaxGuests أو عدد الحضور.
5. حمّل CSV لإرسال الروابط.
6. حمّل guests.json.
7. استبدل assets/data/guests.json بالملف الجديد وارفعه إلى GitHub.

ملاحظة:
هذا الإصدار يعمل على GitHub Pages، ويخفي الاسم من الرابط. لكنه ليس قاعدة بيانات سرية أو Dashboard حقيقية. ربط RSVP بـ Google Sheets، تسجيل مرات الفتح، ولوحة المتابعة يحتاج Backend منفصل.
