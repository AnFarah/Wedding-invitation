ANAS & MARYEM — BOOK INVITATION

1) ارفع جميع الملفات داخل هذا المجلد إلى GitHub Pages واستبدل النسخة القديمة.
2) لتفعيل RSVP:
   - افتح Google Sheet جديد.
   - Extensions > Apps Script.
   - الصق محتوى الملف GOOGLE_APPS_SCRIPT.gs.
   - Deploy > New deployment > Web app.
   - Execute as: Me.
   - Who has access: Anyone.
   - انسخ Web App URL.
   - افتح script.js واستبدل YOUR_GOOGLE_APPS_SCRIPT_URL بالرابط.
3) أي ضغطة على واجهة الدعوة تفتحها.
4) حركة الفتح من الوسط مثل الكتاب.
5) يوم 28 داخل قلب.
6) رابط الموقع والخريطة والتقويم جاهزان.
